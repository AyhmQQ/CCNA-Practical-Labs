## Explore a lab

1. Open a lab above and read its objective and topology.
2. Download its `lab_file.pkt` file and open it in Cisco Packet Tracer.
3. Compare the workspace with `topology.png`.
4. Follow the documented steps and use the review checklist to inspect your own results.
5. Save a separate copy if you want to experiment.

The Packet Tracer version used to create these files has not yet been recorded. If a file does not open, note your version and the error when reporting the issue.
